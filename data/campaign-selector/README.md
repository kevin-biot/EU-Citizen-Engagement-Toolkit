# Campaign Selector Data

Structured selector datasets for campaign-stage assessment and next-step recommendations.

This layer exists to answer:

- what stage a campaign is in
- what the most appropriate next move is
- which template, bundle, or dataset supports that move

## Current Coverage

- [gdpr-campaign-stages.csv](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/data/campaign-selector/gdpr-campaign-stages.csv:1)
- [gdpr-next-step-rules.csv](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/data/campaign-selector/gdpr-next-step-rules.csv:1)

## Scope

Current scope is `gdpr_complaints` only.

The design is generic enough to support other campaign packs later if they follow the same schema.
