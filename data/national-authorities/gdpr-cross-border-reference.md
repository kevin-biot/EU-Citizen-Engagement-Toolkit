# GDPR Cross-Border Reference

Official-source reference set for GDPR complaints that may become cross-border, one-stop-shop, or lead-authority matters.

How to use this file:
- Start with [dpa-complaint-routes.md](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/data/national-authorities/dpa-complaint-routes.md:1) when the question is where to file.
- Use this file when the case involves a large controller, multiple Member States, or visible one-stop-shop delay.
- Pair it with [campaigns/gdpr-complaints/one-stop-shop.md](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/campaigns/gdpr-complaints/one-stop-shop.md:1) for campaign-facing guidance.

Important:
- This is a reference index, not a substitute for legal advice.
- The existence of one-stop-shop does not mean the complainant must find the lead authority alone before filing.
- The national decision in its authentic language remains the primary legal source even where the EDPB register provides a summary.
