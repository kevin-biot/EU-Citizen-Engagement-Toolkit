# National CPC Authorities (Markdown view)

Source: data/national-authorities/national-cpc-authorities.csv

This file captures the detailed consumer-protection cooperation (CPC) entries published through the official Commission page. It is intentionally more granular than the summary national routing file because the CPC layer is often split by sector, region, or legal instrument.

Coverage in this snapshot: 364 EU Member State entries across 26 countries. 301 rows publish a non-empty legal-responsibility field in the source snapshot.

Important note: the official source itself is heterogeneous. Some rows list explicit legal responsibilities and some do not. This Markdown view mirrors that source reality rather than pretending every entry is a single national general-consumer authority.
