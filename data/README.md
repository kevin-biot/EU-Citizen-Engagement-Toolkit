# Data

Structured reference data used by the toolkit, including contact lists, political officeholder references, and contextual case studies.

## Current Sections

- `mep-contacts/`: Parliament-side reference data, extracts, and committee mappings.
- `institutional-contacts/`: Functional mailboxes, portals, and access-to-documents routes.
- `commission-reference/`: Current College of Commissioners, cabinet contacts, spokesperson roster, media surfaces, and current Commissioners' Project Groups.
- `community-contacts/`: Public-interest digital-rights, journalism-support, and newsroom contact routes for community escalation and media outreach.
- `national-authorities/`: Country-level digital enforcement directory, DPA complaint-entry routes, detailed CPC consumer entries, equality bodies, web-accessibility bodies, Markdown views, and a starter issue router.
- `case-studies/`: Example or supporting reference material.
