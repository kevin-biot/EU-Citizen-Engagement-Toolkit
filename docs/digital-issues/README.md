# Digital Issues Playbooks

Citizen-facing playbooks for common digital problems that cross EU and national enforcement layers.

These are not legal opinions. They are action guides that help a person identify the likely route, preserve evidence, and decide what to do first.

## How To Use These

Start with the playbook that matches the problem you actually experienced.

Each playbook is designed to answer:
- what this issue usually is
- what evidence to save immediately
- what route to try first
- when to escalate
- which national and EU layers may both matter
