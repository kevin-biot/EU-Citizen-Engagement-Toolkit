# First Step By Problem

This page is for speed.

## My Platform Restricted Or Removed Me

First step:

- send a clean first review request to the platform

Then:

- preserve timestamps, screenshots, notices, and URLs

Open:

- [Platform Account Suspension Or Removal](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/docs/digital-issues/platform-account-suspension.md)

## A Company Ignored My GDPR Request

First step:

- send or repeat a clean controller-side rights request

Then:

- if still ignored, use the correct DPA intake route

Open:

- [GDPR Data Rights](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/docs/digital-issues/gdpr-data-rights.md)
- [DPA Complaint Routes](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/data/national-authorities/dpa-complaint-routes.md)

## A Regulator Is Ignoring My GDPR Complaint

First step:

- send a procedural follow-up before widening the matter

Then:

- only move to NGO, journalist, or MEP pressure if the chronology is clean

Open:

- [GDPR Complaints Campaign](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/campaigns/gdpr-complaints/README.md)

## A Public Website Or App Is Inaccessible

First step:

- report the failure to the service owner and ask for a practical fallback

Then:

- use the national accessibility or equality body if the issue is not fixed

Open:

- [Digital Accessibility Failure](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/docs/digital-issues/digital-accessibility-failure.md)
- [National Web Accessibility Bodies](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/data/national-authorities/national-web-accessibility-bodies.md)

## I Was Harmed By A Seller, Trader, Or Marketplace

First step:

- send the documented trader or platform complaint first

Then:

- move to consumer authority or support routes if the facts are ignored

Open:

- [Cross-Border Consumer Dispute](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/docs/digital-issues/cross-border-consumer-dispute.md)
- [Online Scam And Marketplace Harm](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/docs/digital-issues/online-scam-and-marketplace-harm.md)

## I Think This Is Bigger Than My Own Case

First step:

- organize the facts so the pattern is visible, not just the frustration

Then:

- choose NGO, journalist, or political routes carefully
