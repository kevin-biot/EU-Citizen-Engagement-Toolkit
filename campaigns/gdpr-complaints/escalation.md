# GDPR Complaint Escalation

## Escalation Ladder

1. controller rights request
2. DPA complaint
3. structured regulator follow-up
4. privacy-rights organisation or issue bundle route
5. journalist or public-interest escalation
6. political or oversight pressure where the issue is clearly systemic

## Escalate When

- the controller ignores or stonewalls the rights request
- the DPA fails to acknowledge or advance the case in a visible way
- the same pattern affects multiple users
- the issue has clear public-interest value beyond one complainant

## Do Not Escalate Publicly Yet When

- the evidence file is incomplete
- you cannot explain the issue in three factual lines
- you do not yet know whether this is a controller failure or an enforcement failure

## Split The Ask Properly

Controller ask:

- answer the rights request properly

DPA ask:

- investigate and progress the complaint
- use the correct official intake route and channel for the target country: [dpa-complaint-routes.md](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/data/national-authorities/dpa-complaint-routes.md:1)

NGO ask:

- validate, support, or amplify the issue

Journalist ask:

- assess whether the issue has wider public-interest value

MEP ask:

- apply pressure on systemic under-enforcement or broader governance failure
