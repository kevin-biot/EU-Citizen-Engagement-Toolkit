# GDPR Complaint Message Tracks

## Message Track 1: Individual Rights

Use when the goal is remedy for one person.

Core line:

- this is a concrete rights failure that can still be fixed directly if the controller or authority acts properly

Tone:

- factual
- narrow
- procedural

## Message Track 2: Systemic Abuse

Use when one company pattern affects many users.

Core line:

- this is not an isolated complaint but a repeatable design or governance problem

Tone:

- evidence-led
- pattern-focused
- public-interest oriented

## Message Track 3: Enforcement Failure

Use when the issue has become regulator delay or under-action.

Core line:

- the harm is no longer only the original GDPR breach but the failure to enforce in a timely and legible way

Tone:

- disciplined
- non-ranting
- document-heavy

## Message Track 4: Media

Use when the issue is ready for journalist review.

Core line:

- here is a documented privacy or enforcement failure with broader public implications, not just a private grievance

Requirements before use:

- clear timeline
- concise summary
- one or two strongest documents
- clear statement of what is systemic
