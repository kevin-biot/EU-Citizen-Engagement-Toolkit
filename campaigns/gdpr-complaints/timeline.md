# GDPR Complaint Timeline

## Phase 1: Stabilize The Facts

- send or confirm the rights request
- capture proof of submission
- log all dates
- preserve all replies

## Phase 2: File Or Refine The Complaint

- choose the competent DPA route
- file with a clean evidence pack
- capture acknowledgement and case number

## Phase 3: Structured Follow-Up

- follow up if there is silence or obvious non-progression
- keep follow-up factual and date-based
- do not broaden the theory before the facts are clear

## Phase 4: Escalate If The Pattern Is Bigger

- move to NGO validation or support
- prepare a public-interest framing note
- identify whether the problem is company abuse, cross-border stalling, or regulator failure
- if the case is cross-border, use [one-stop-shop.md](/Users/kevinbrown/EU-Citizen-Engagement-Toolkit/campaigns/gdpr-complaints/one-stop-shop.md:1) before assuming which authority should be lead

## Phase 5: Public Or Political Pressure

- contact journalists only when the case file is coherent
- contact MEP or committee routes when the issue is clearly systemic or enforcement-related

## Cadence Rule

Do not send five escalations in one day.

The better pattern is:

- document
- file
- wait for the proper window
- follow up
- escalate with the stronger file
